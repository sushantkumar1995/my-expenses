# My Expenses PWA
Static, offline-first monthly expense tracker for GitHub Pages.

## Publish
Upload index.html, style.css, app.js, manifest.json and sw.js to the repository root.
Then enable GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root).

## iPhone
Open the GitHub Pages URL in Safari, tap Share, then Add to Home Screen.

Data is stored locally in the browser. Use Backup > Export backup periodically.
